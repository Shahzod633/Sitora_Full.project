# ASTER — Abandoned But Not Forgotten

Демо первой главы интерактивного веб-комикса на React, TypeScript, Vite и GSAP. Глава 1 «Where It All Began» состоит из 33 связанных сюжетных битов: полёт Aster от Земли, разговор экипажа в кабине, посадка и дозаправка на Луне, место посадки Apollo 11 с интерактивным историческим флешбэком и отлёт к Марсу.

Все иллюстрации в этой сборке — временные заглушки. Финальные работы художников подключаются через манифест ассетов без изменения кода.

## Локальный запуск

Установите зависимости и запустите сервер разработки из корня проекта.

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite, и нажмите **Begin the Story** (или выберите главу в списке **Chapters**; ссылка `/?chapter=2` сразу предлагает вторую главу). Пауза — кнопка ⏸ или Esc: там же выбор главы, перезапуск и громкость музыки, эффектов и голосов. Реплики листаются кликом, касанием, пробелом, Enter или стрелкой вправо; клик во время кинематографичных сцен ускоряет их. Голоса Мары, Эли и Пипа синтезируются в браузере по мере появления букв. Демо работает без папки `Voices/`.

В режиме разработки внизу слева показывается панель раскадровки (переключается клавишей `` ` ``), а адрес вида `/?beat=B17` запускает главу с нужного бита.

## Сборка

```sh
npm run build
npm run typecheck
```

Vite сохранит готовую версию в `dist/`. Панель раскадровки и отладочные хуки в сборку не попадают.

## Структура

- `src/chapters/chapter01/script.ts` — все реплики сценария, дословно и по порядку.
- `src/chapters/chapter01/stages.ts` — шесть переиспользуемых сцен: слои, адаптивные позиции, глубина параллакса, ракурсы камеры.
- `src/chapters/chapter0N/` — сценарий, сцены и раскадровка каждой главы (только данные) и её интерактивы.
- `src/story/` — движок раскадровки: `Director` (таймлайны GSAP, камера, переходы), рендер сцен, эффекты, проверка данных.
- `src/data/assetManifest.ts` — ассеты, места для финальных иллюстраций и фотографий NASA.

Подробное описание архитектуры, таблица битов, список недостающих иллюстраций и отчёт о тестировании: [docs/CHAPTER01_STORYBOARD.md](docs/CHAPTER01_STORYBOARD.md).

## Права

Команда ASTER не предоставляет открытую лицензию на собственный код и творческие материалы проекта, включая сценарий, персонажей и иллюстрации. Для сторонних компонентов действуют их собственные лицензии. Условия использования шрифта Barlow Condensed приведены в [OFL.txt](public/assets/fonts/OFL.txt). Исторические сведения об Apollo 11 приведены по материалам NASA; сведения о Mars Pathfinder и марсоходах — по страницам NASA из [docs/NASA_SOURCES.md](docs/NASA_SOURCES.md); фотографии NASA в сборку пока не добавлены. Aster, экипаж, лунная база и возвращение Sojourner — вымысел.
