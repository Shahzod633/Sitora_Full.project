# ASTER — Abandoned But Not Forgotten

Демо первой главы интерактивного веб-комикса на React, TypeScript и Vite. Корабль Aster покидает Землю, экипаж обсуждает полёт на мостике, а на Луне игрок может осмотреть посадочную ступень Apollo 11 и открыть историческую справку.

## Локальный запуск

Установите зависимости и запустите сервер разработки из корня проекта.

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite, и нажмите **Begin Chapter 01**. Голоса Мары, Эли и Пипа синтезируются в браузере по мере появления букв. Демо работает без папки `Voices/`.

## Сборка

```sh
npm run build
```

Vite сохранит готовую версию в `dist/`.

## Права

Команда ASTER не предоставляет открытую лицензию на собственный код и творческие материалы проекта, включая сценарий, персонажей и иллюстрации. Для сторонних компонентов действуют их собственные лицензии. Условия использования шрифта Barlow Condensed приведены в [OFL.txt](public/assets/fonts/OFL.txt).
